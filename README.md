Pinnacle Props compares player-prop prices at the same line against Pinnacle fair probabilities. This repository contains only the Streamlit app runtime and app tests; research data and private project history are excluded.

Deploy main with app.py on Streamlit Community Cloud. Set PP_DEPLOYMENT="cloud", PP_STORE="local", ODDS_API_KEY and APP_PASSPHRASE in app settings only. Visitors must unlock the app before any data or live control is shown. Live refresh checks the free account balance against its full estimate and the 100,000-credit floor; no live project allowance or cloud reserve. Shared archive storage is not connected yet.
